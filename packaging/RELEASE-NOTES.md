## VoiceKeys v0.2.4 — Windows x64

**只下一个文件：`VoiceKeys-Setup-0.2.4.exe`**，双击安装。不需要解压 zip。

> **如果你装过 v0.2.3，请务必升级**：v0.2.3 有一个严重问题——除极少数词外，大部分关键词都不会触发（原因见下）。

### 这一版修了什么

| 改动 | 说明 |
|---|---|
| **修复：大部分关键词不触发（v0.2.3 严重 bug）** | v0.2.3 里"静音门到期后让 M2 裁判"的那段代码引用了一个不存在的变量，异常被吞掉，导致**所有需要 M2 确认的词在门到期时静默失败**，只有 M1 极自信（快速通道）的词还能响。现已改为统一交给同一条裁决链路，修复后现场日志验证「匹配 → 门到期 → 确认 → 执行」完整走通 |
| **确认日志可诊断** | 每次 M2 裁决都会把 **M2 的转录文本 + top1 分数**写进日志，为什么否决一眼能看出来 |
| **Calibrator 默认值** | 普通用户**默认关闭**（与上一版一致）；开发者用 `start-dev.cmd`（或 `VK_DEV=1`）启动时默认开启，方便我们自己调算法 |

### 沿用 v0.2.3 的匹配改进

| 改动 | 说明 |
|---|---|
| 静音门驱动的匹配 | 最后有声帧后连续 3 帧静音才跑一次匹配；600ms 门从该帧起算，第 6 帧执行/放弃；句中提到的词不触发 |
| M1/M2 都只看句尾 | 不从整句话中间挑词 |
| 拼音部分相似打分 | 音节级部分分 + 长度折扣：挺好说/听我说 0.67→0.78，站厅视频/暂停视频 0.75→0.96，定视频/暂停视频 0.71→0.53 |
| 短文本门修复 | 门口文本比关键词短时不再直接 0 分 |
| 每道静音门各自执行 | 一句话里多个关键词、同一词说两遍，各自有静音门就各自触发 |

### 实测数据（70 条真实录音，1.7B 老师模型当答案）

统计口径：**分母 = 1.7B 数出的关键词出现次数**（不是录音条数），允许一条录音多次执行。

```
关键词总次数 75 次 → 命中 69 次 = 92.0%
误触发 0 次（5 条无关键词录音）
漏 6 次中：5 次是"句中提及"（本来就不该触发）
           1 次是连说两遍、间隔仅 100ms 共用一道门（说话节奏问题，非算法）
→ 排除句中提及后：69/69 = 100%
```

**已知限制**：

- 14M 流式模型偶尔把「我说完了 / 听我说 / 暂停视频」听成完全无关的词，这类会漏；属模型能力，后续换/升级模型再解决
- 两遍关键词之间停顿不足 300ms 时会共用一道静音门，只执行一次
- 媒体类计划是 toggle（按一次空格）：同一动作被连续执行两次会"播了又暂停"，正常说一遍不会重复

### 装在哪里

```
程序：%LOCALAPPDATA%\Programs\VoiceKeys
数据：%LOCALAPPDATA\VoiceKeys                    模型/词表/设置/录音/日志
开始菜单：%APPDATA%\Microsoft\Windows\Start Menu\Programs\VoiceKeys\
桌面：VoiceKeys.lnk
注册表：HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\VoiceKeys
```

全部在用户目录，**不需要管理员权限、不弹 UAC**。

### 升级旧版

直接运行新 setup 覆盖安装即可；**数据目录（词表、设置、录音、模型）不会被动**。

### 校验

```
Get-FileHash .\VoiceKeys-Setup-0.2.4.exe -Algorithm SHA256
```

与 release 页面附带的 SHA256 对比一致即可。
