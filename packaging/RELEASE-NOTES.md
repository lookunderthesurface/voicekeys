## VoiceKeys v0.2.7 — Windows x64

**只下一个文件：`VoiceKeys-Setup-0.2.7.exe`**，双击安装。不需要解压 zip。
安装包不带语音模型，首次运行会提示下载（约 205MB：M1 流式 127MB + M2 确认 74MB）。

### 这一版的变化

**触发层换成大模型（最重要）**
- M1 从 `streaming-zipformer-zh-14M`（24MB，1400 万参数）换成 **`streaming-zipformer-zh-int8-2025-06-30`**（约 160MB，multi_zh_hans 多语料、zipformer-large），旧模型保留可回滚。
- 同一批 130 条真实素材：M1 候选命中 93.3% → **100%**，字错率 24.4% → **8.6%**，命令句字错率 23.7% → **7.2%**。
- 代价：常驻内存 +177MB（约 291MB），启动加载约 5 秒（只影响启动）。

**误触发修复**
- 匹配器：同韵母、不同声母的音节不再算 0.85 分（只有 zh/z、ch/c、sh/s、n/l 这类口音家族才给高分）。游戏解说里的「大龙」曾以 0.85 分同时骗过 M1 和 M2 触发「发送」，现在只有 0.35。
- 「发送」单独阈值：M1/M2 都提到 **0.90**；全局 M2 阈值 0.70 → **0.75**（130 条素材回归无损失）。
- 一句话重复执行：门到期后立刻重置 ASR 流，修掉"喊一次播放视频 → 播放后又被暂停"（同一句话 2.4 秒内执行两次）。

**稳定性**
- 修掉 M2 确认进程重复常驻（空闲卸载与预热的竞态，曾出现两个 188MB 进程）。
- 录音编号改为按「index + 磁盘文件」取最大值并独占写入，重启/清理后不再覆盖旧素材。
- M1 候选门槛 0.15 → 0.50，且 loose 路径也遵守每词阈值（此前单词阈值对 loose 候选无效）。

**其他**
- DSH 控制原语：`dsh.send`（点发送按钮，草稿为空/重复/生成中会拒绝）、`dsh.focus`（把光标放进 DSH 输入框）。
- 新增绑定：发送 / 发送消息 / 发送出去 → dsh.send；输入框 / 光标 → dsh.focus；写消息 → dsh.focus + 开始听写。

### 安装 / 升级
- 直接覆盖安装即可；数据目录 `%LOCALAPPDATA%\VoiceKeys` 保留（录音、词表、设置、模型）。
- 校验：
```powershell
Get-FileHash .\VoiceKeys-Setup-0.2.7.exe -Algorithm SHA256
```
