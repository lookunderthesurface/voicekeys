## VoiceKeys v0.2.2 — Windows x64

**只下一个文件：`VoiceKeys-Setup-0.2.2.exe`**，双击安装。不需要解压 zip。

### 这一版改了什么

| 改动 | 说明 |
|---|---|
| **判定逻辑重写** | 以前只拿"最像的那个词"做判断；现在**给所有关键词打分**，并看第一名领先第二名多少。M2 认同候选词必须过"该词自己的阈值"，证据不足就不执行 |
| **两个模型都困惑时才听 M1** | 「听我说 / 我说完了」这类近音词，只有 M2 的两个词分数真的接近（差 < 0.15）才参考 M1 的意见；M2 分得清时以 M2 为准 |
| **修打分 bug** | 之前两字词允许用单个汉字去比，导致「静音」被「京」打成满分。已修，同音字不再虚高 |
| **录音素材 6 秒** | 触发前 5 秒 + 触发后 1 秒（后 1 秒用来看"正常静音段"长什么样） |
| **修两个录音丢失 bug** | ① 编号从"条数"算起，清理素材后会重号并**覆盖旧录音**；② 写索引后没更新缓存，同一秒内多次触发也重号。都改成"现有最大编号 + 1"，并修好历史数据 |
| **判定逻辑用大模型验证** | 用 Qwen3-ASR 老师模型当答案，在 119 条真实录音上核对最终动作 |

### 实测数据（119 条真实录音，以老师模型为答案）

```
有明确关键词的录音 68 条 → 动作全部正确
误触发 6 条（8.1%）       ← 全是在闲聊里"听出"关键词
漏响 0
```

**已知限制**：说「继续播放，(停顿 0.8 秒) 可以吗」这种"词后停顿再接着说"的句子，静音门会当成命令；这是 600ms 静音门的固有局限，暂不处理。

### 装在哪里

```
程序：%LOCALAPPDATA%\Programs\VoiceKeys
数据：%LOCALAPPDATA\VoiceKeys                    模型/词表/设置/录音/日志
开始菜单：%APPDATA%\Microsoft\Windows\Start Menu\Programs\VoiceKeys\
桌面：VoiceKeys.lnk
注册表：HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\VoiceKeys
```

全部在用户目录，**不需要管理员权限、不弹 UAC**。

### 升级旧版

直接运行新 setup 覆盖安装即可；**数据目录（词表、设置、录音、模型）不会被动**。

### 卸载时

**会删**：程序目录、开始菜单项、桌面快捷方式、注册表卸载项

**不会删**：数据目录 `%LOCALAPPDATA%\VoiceKeys`

### 系统要求

- Windows 10/11 x64（自带 Node 运行时，不需要装 Node）
- 麦克风
- 可选：[Handy](https://github.com/cjpais/Handy)（「听我说 / 我说完了」用）
