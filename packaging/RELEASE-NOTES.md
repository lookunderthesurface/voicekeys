## VoiceKeys v0.2.5 — Windows x64

**只下一个文件：`VoiceKeys-Setup-0.2.5.exe`**，双击安装。不需要解压 zip。

### 这一版改了什么

| 改动 | 说明 |
|---|---|
| **全新应用图标** | 青绿底 + 暖白键帽轮廓 + 三段声纹，一眼是「用声音按下的按键」。已接入：启动器 `VoiceKeys.exe`、安装器 `Setup.exe`、卸载器 `uninstall.exe`、开始菜单/桌面快捷方式、控制台页面 favicon。图标含 **16/20/24/32/40/48/64/96/128/256** 十档尺寸，任务栏、资源管理器、属性页都清晰 |
| **确认日志更清楚** | 每次 M2 裁决合成一行日志（含 M2 转录文本 + 最高分），误判/否决可以直接从日志定位 |

### 上一版（v0.2.4）的关键修复，本版继续包含

| 修复 | 说明 |
|---|---|
| v0.2.3「大部分关键词不触发」 | 静音门到期后的 M2 裁决引用了未定义变量，异常被吞掉 → 除快速通道外都不响应。现在统一交给同一条裁决链路，已用线上日志验证「匹配 → 门到期 → 确认 → 执行」完整走通 |
| 静音门驱动匹配 | 最后有声帧后连续 3 帧静音才跑一次匹配；600ms 门从该帧起算，第 6 帧执行/放弃；句中提到的词不触发 |
| M1/M2 都只看句尾 | 不从整句话中间挑词；修掉「句中说『静音』也触发」和「句尾真词被句中弱词顶掉」 |
| 拼音部分相似打分 | 音节级部分分 + 长度折扣：挺好说/听我说 0.67→0.78，站厅视频/暂停视频 0.75→0.96，定视频/暂停视频 0.71→0.53 |
| 短文本门修复 | 门口文本比关键词短时不再直接 0 分 |
| 每道静音门各自执行 | 一句话里多个关键词、同一词说两遍，各自有静音门就各自触发 |

### 实测数据（70 条真实录音，1.7B 老师模型当答案）

统计口径：**分母 = 1.7B 数出的关键词出现次数**，允许一条录音多次执行。

```
关键词总次数 75 次 → 命中 69 次 = 92.0%
误触发 0 次（5 条无关键词录音）
漏 6 次中：5 次是「句中提及」（本来就不该触发）
           1 次是连说两遍、间隔仅 100ms 共用一道门（说话节奏问题，非算法）
→ 排除句中提及后：69/69 = 100%
```

**已知限制**：

- 14M 流式模型偶尔把「我说完了 / 听我说 / 暂停视频」听成完全无关的词，这类会漏；属模型能力，后续换/升级模型再解决
- 两遍关键词之间停顿不足 300ms 时会共用一道静音门，只执行一次
- 媒体类计划是 toggle（按一次空格）：同一动作被连续执行两次会「播了又暂停」，正常说一遍不会重复

### 装在哪里

```
程序：%LOCALAPPDATA%\Programs\VoiceKeys
数据：%LOCALAPPDATA\VoiceKeys                    模型/词表/设置/录音/日志
开始菜单：%APPDATA%\Microsoft\Windows\Start Menu\Programs\VoiceKeys\
桌面：VoiceKeys.lnk
注册表：HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\VoiceKeys
```

全部在用户目录，**不需要管理员权限、不弹 UAC**。

### 升级旧版

直接运行新 setup 覆盖安装即可；**数据目录（词表、设置、录音、模型）不会被动**。

### 校验

```
Get-FileHash .\VoiceKeys-Setup-0.2.5.exe -Algorithm SHA256
```

与 release 页面附带的 SHA256 对比一致即可。
