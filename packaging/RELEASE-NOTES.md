## VoiceKeys v0.2.6 — Windows x64

**只下一个文件：`VoiceKeys-Setup-0.2.6.exe`**，双击安装。不需要解压 zip。

### 这一版新增

| 新增 | 说明 |
|---|---|
| **托盘图标** | 后台运行时在 Windows 右下角通知区常驻 VoiceKeys 图标（和普通 APP 一样）。**双击**打开控制台；右键菜单：打开控制台 / 退出 VoiceKeys。Windows 11 默认会把新图标折叠进「隐藏的图标」面板，启动器会自动把它提升为常驻显示 |
| **开机自启开关** | 控制台首页新增「运行方式」面板，一个勾选框控制是否登录 Windows 后自动启动。开启＝写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（以 `--no-browser` 静默启动，不弹浏览器）；关闭＝删除该登记项 |
| **旧录音归档** | 与当前录音规则不一致的旧素材移到 `%LOCALAPPDATA%\VoiceKeys\archive\legacy-recordings\`（旧的 4 秒窗口录音、早期校准录音），带 README 说明；`capture/`（当前 6 秒规则）不受影响 |

### 录音规则（不变，这里写清楚免得误会）

**只有触发关键词时才存录音**，但存的是固定 **6 秒窗口 = 触发前 5 秒 + 触发后 1 秒**：

- 说一个 1 秒的词，窗口里就会有约 4 秒静音——这是为了覆盖"触发前后"的上下文，属于设计
- 元数据在 `capture/index.jsonl`，`voicedMs` 是真实有声时长（中位数约 1.2 秒，占 6 秒窗口约 20%）
- 格式统一：16000Hz / 单声道 / 16bit

### 之前版本的关键修复，本版继续包含

| 修复 | 说明 |
|---|---|
| v0.2.3「大部分关键词不触发」 | 静音门到期后的 M2 裁决引用了未定义变量 → 除快速通道外都不响应。现已统一裁决链路 |
| 静音门驱动匹配 | 最后有声帧后连续 3 帧静音才跑一次匹配；600ms 门从该帧起算，第 6 帧执行/放弃；句中提到的词不触发 |
| M1/M2 都只看句尾 | 不从整句中间挑词 |
| 拼音部分相似打分 | 音节级部分分 + 长度折扣 |
| 每道静音门各自执行 | 一句话里多个关键词各自触发 |
| 新图标 | 青绿键帽 + 三段声纹，10 档尺寸 |

### 实测数据（70 条真实录音，1.7B 老师模型当答案）

```
分母 = 1.7B 数出的关键词出现次数（允许一条录音多次执行）
75 次 → 命中 69 次 = 92.0%
误触发 0 次（5 条无关键词录音）
漏 6 次中 5 次是句中提及（本就不该触发）
排除句中提及后：69/69 = 100%
```

**已知限制**：

- 14M 流式模型偶尔把词听成完全无关的词，这类会漏
- 两遍关键词间隔不足 300ms 会共用一道静音门，只执行一次
- 媒体类是 toggle（按一次空格），同一动作连续执行两次会「播了又暂停」

### 装在哪里

```
程序：%LOCALAPPDATA%\Programs\VoiceKeys
数据：%LOCALAPPDATA\VoiceKeys（词表/设置/录音/日志/归档）
自启：HKCU\Software\Microsoft\Windows\CurrentVersion\Run\VoiceKeys（仅在 GUI 里打开时存在）
开始菜单：%APPDATA%\Microsoft\Windows\Start Menu\Programs\VoiceKeys\
桌面：VoiceKeys.lnk
```

全部在用户目录，**不需要管理员权限、不弹 UAC**。

### 升级旧版

直接运行新 setup 覆盖安装；数据目录（词表、设置、录音、模型）不会被动。

### 校验

```
Get-FileHash .\VoiceKeys-Setup-0.2.6.exe -Algorithm SHA256
```

与 release 页面附带的 SHA256 对比一致即可。
