计划与关键词

生成方式
一个计划一行；同一计划的多个关键词并排放在一起。点词名＝设为校准目标，词旁数字是旧的 KWS 门限（现在不影响识别，仅供参考），× 解绑。

事件

运行方式

开启后在 HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run 登记一项，以 --no-browser 静默启动；关闭即删除。后台运行时右下角通知区有 VoiceKeys 托盘图标，双击打开控制台。

快照与恢复

改算法 / 改脚本前先打快照；改坏了点「选择恢复」回到任一版本。恢复前的改动会存进 git stash，不会丢。
