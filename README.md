# VoiceKeys

**用说话控制电脑的本地语音助手。** 常开监听，说完一个词 + 静音 0.6 秒，就执行你绑定的动作。

- 🎙️ **完全本地**：流式识别 + 确认模型都在本机跑，不联网、不上传音频
- ⚡ **说完就动**：感知延迟 ≈ 静音门长度（默认 600ms）
- 🧩 **动作可自己定**：11 个安全原语（音量、静音、媒体播放/暂停、按键、Handy 录音…），一句话生成计划
- 🔧 **算法可自己改**：匹配、静音门、采样三个算法都是明文 `.js`，改坏了点一下还原

> Windows 10/11 · 不需要 GPU · 常驻内存约 250MB · CPU 约 1–2%

## 快速开始（3 步）

```bash
# 1. 装运行时依赖（原生模块，约 30MB）
npm install --prefix lib

# 2. 下载语音模型（约 205MB，只下一次）
node scripts/fetch-models.cjs

# 3. 启动，然后用浏览器打开 http://127.0.0.1:19600/
node app/server.js
```

首次运行会在 `%LOCALAPPDATA%\VoiceKeys\` 建好用户目录（设置、绑定表、日志、录音素材都在那儿）。

## 它怎么工作

```
麦克风 100ms/帧
   ├─→ M1 流式识别（zipformer-large，≈160MB，一直在听，边说边出字）
   │        ↓ 判断"这句话结尾像不像某个绑定词"
   │     像 → 静音门开始计时（默认 600ms）
   │        ├─ 门内：把这段音频交给 M2 确认（80MB，约 40ms）
   │        └─ 门到期：按结果执行动作
   └─→ 环形缓冲（给 M2 和录音素材用）
```

判断顺序（可在 GUI 里逐词调阈值）：

| 情况 | 谁决定 |
|---|---|
| 这段音频有 < 300ms 声音 | 丢弃（不是说话） |
| M1 很自信（相似度 ≥ 0.95） | **M1 说了算**，不叫 M2 |
| M1 不自信 | **M2 说了算**（含改判） |
| M2 说"这不是任何词" | 丢弃 |

实测（30 段真人录音）：M1 单独 63%、M2 单独 87%、两段式合起来 88%，错词 0。

## 绑定一个动作

三个入口，随便挑：

1. **一句话生成**：界面里输入「把系统音量调到 40%」→ 本地 Ollama 或任意 OpenAI 兼容 API 生成计划
2. **手写**：界面里直接粘贴计划 JSON
3. **让你的 AI 写**：界面会告诉你 `plans.json` 的绝对路径，让你的 agent 往里写这段就行

```json
{
  "音量四十": {
    "say": "音量四十",
    "plan": { "steps": [{ "op": "audio.volume.set", "percent": 40 }] },
    "pauseMs": 600
  }
}
```

同一个计划可以绑多个说法（同义词），例如「暂停视频 / 暂停播放 / 停止播放」。

## 改算法

界面里「算法（可自定义）」→ 点 **① 备份并开始编辑**（会把当前实现展开成可改的 `.js` 并做快照）→ 改 → 保存 → 重启生效。

改坏了点 **② 一键还原全部**，回到快照。

三个角色：

| 角色 | 作用 | 必须导出 |
|---|---|---|
| `matcher` | 计算"这句话和某个词有多像" | `match` / `bestScore` |
| `gate` | 静音门长度策略 | `pauseMs` / `ignoreNoisy` |
| `sampler` | 哪些录音值得存下来 | `decide` |

## 校准（实验功能，默认关闭）

内置一个"老师模型"（Qwen3-ASR 0.6B，可选）复核录下来的素材，给出**加/删同义词**的建议：

- M1 听不清、M2 听对、老师也认同 → 建议把这个谐音加成同义词
- 某个同义词老是误触发 → 建议删掉

在界面上勾「展开」才显示，默认关闭。算法还在演进，别指望它。

## 目录说明

| 位置 | 内容 |
|---|---|
| `app/` | 后端（Node，无构建步骤） |
| `app/algorithms/` | 三个可替换算法的默认实现 |
| `app/ui.html` | 前端（单文件，零依赖） |
| `lib/` | 运行时依赖（原生模块，npm 装） |
| `scripts/` | 模型下载、备份还原、校准、自检等工具 |
| 用户目录 `%LOCALAPPDATA%\VoiceKeys\` | 设置、绑定、录音素材、模型、日志 |

## 已知限制

- 只支持 Windows（录音与窗口控制用了 Win32 API）
- 媒体控制靠"激活播放器窗口 + 按空格"，会闪一下焦点；全局媒体键控制不了爱奇艺这类桌面 App
- 识别率取决于麦克风与口音，词表小（十几个词）时最稳
- 校准是实验功能
